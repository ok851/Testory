Testory 使用手册

入门

📦 安装指南

系统要求

  • 操作系统：Windows 10 / Windows 11（64 位）
  • 内存：建议 8GB 及以上
  • 磁盘空间：基础安装约 500MB，完整组件约 2GB
  • 网络：首次使用部分功能需联网下载组件

安装步骤

  1. 下载安装包

    从官网下载 Testory_Setup.exe 安装程序。

  2. 运行安装向导

    双击安装包，按照提示完成安装。安装过程约 1-3 分钟。

    💡 提示：若系统缺少 WebView2 运行时，安装程序会自动静默安装，请耐心等待。

  3. 启动软件

    从开始菜单或桌面快捷方式启动 Testory。首次启动可能需要 15-60 秒初始化。

  4. 按需安装组件

    首次使用 Web 测试、视觉定位等功能时，软件会自动下载所需组件。您也可以提前在「设置 → 组件管理」中安装。

卸载方法

通过「控制面板 → 程序和功能」找到 Testory，选择卸载即可。用户数据默认保留，如需完全清除，请手动删除 %LOCALAPPDATA%\Testory 文件夹。

入门

🚀 快速上手

创建您的第一个项目

  1. 新建项目

    启动软件后，点击「新建项目」，输入项目名称和描述，选择项目类型。

  2. 选择测试类型

    根据您的需求选择：Web 自动化、接口测试、AI 测试、移动端测试或桌面混排。

  3. 录制或编写用例

    使用浏览器录制功能自动生成步骤，或手动编排测试步骤。

  4. 运行测试

    点击「运行」按钮，查看实时执行过程和结果报告。

界面概览

  • 左侧导航：项目列表、用例管理、执行记录、缺陷管理等
  • 顶部工具栏：运行、停止、调试、设置等快捷操作
  • 主工作区：用例编辑、步骤编排、结果查看
  • 底部面板：执行日志、控制台输出、进度显示
功能

✨ 功能介绍

功能

🌐 Web 自动化测试

主要功能

  • 基于 Playwright 的多浏览器驱动（Chromium / Chrome / Edge / Firefox）
  • 浏览器扩展拾取元素，步骤可视化编辑
  • 智能元素采集与定位器自愈
  • 支持 iframe、弹窗、文件上传等复杂场景
  • 断言与数据提取
  • 可与桌面 ERP 步骤混排，覆盖跨系统业务流

快速开始 Web 测试

  1. 在项目中选择「Web 测试」
  2. 点击「录制」按钮，选择浏览器
  3. 在浏览器中操作，步骤会自动记录
  4. 停止录制，自动生成测试用例
  5. 编辑步骤、添加断言
  6. 运行测试，查看结果
📌 注意：首次使用 Web 测试时，需要下载 Playwright Chromium 浏览器（约 150MB），请耐心等待。
功能

🔌 接口自动化测试

主要功能

  • REST API 用例独立管理
  • 支持 GET / POST / PUT / DELETE 等常用方法
  • 断言与变量提取（JSONPath / 正则表达式）
  • 环境参数化与全局变量
  • 与 Web 用例同项目编排
  • 支持前置/后置脚本（JavaScript）
  • 接口文档导入（Postman / OpenAPI）

编写接口用例

  1. 选择「接口测试」模块
  2. 点击「新建用例」，输入接口名称和 URL
  3. 配置请求方法、Headers、Body
  4. 添加断言（响应状态码、响应内容等）
  5. 运行并查看结果
功能

🤖 AI 自动化测试

主要功能

  • 自然语言生成用例：用中文描述测试场景，AI 自动生成可执行步骤
  • 智能元素定位：视觉 + 语义双重定位，元素变化自动自愈
  • 失败诊断与修复：测试失败时 AI 分析原因并给出修复建议
  • 自主探索：Hermes Agent 自主探索应用，发现潜在问题
  • 对话式改步骤：用自然语言修改测试步骤

配置 AI 模型

Testory 支持两种 AI 使用方式：

💻 本地 Ollama（推荐）
  1. 安装 Ollama
  2. 拉取模型：ollama pull llama3:8b-instruct
  3. 在 Testory AI 设置中选择「本地 Ollama」
☁️ 云端 API
  1. 获取 OpenAI 兼容的 API Key
  2. 在 AI 设置中填入 API 地址和密钥
  3. 选择对应模型即可使用
功能

📱 移动端测试

主要功能

  • Android 真机与模拟器支持
  • USB 连接与无线调试（Android 11+）
  • 投屏录制与点屏录制
  • Appium 关键字编排
  • 与 Web / 接口用例同平台管理
  • 一键生成移动端用例

连接 Android 设备

  1. 手机开启「开发者选项」和「USB 调试」
  2. 用 USB 线连接电脑
  3. 手机上允许 USB 调试授权
  4. 在 Testory 中点击「连接设备」
  5. 连接成功后即可开始录制测试
功能

🖥️ 桌面混排测试

主要功能

  • Windows UIA + 视觉定位双引擎
  • Web、ERP 与桌面客户端步骤可在同一用例中混排执行
  • 桌面应用元素拾取
  • 图片识别与文字识别（OCR）
  • 键盘鼠标操作模拟
💡 提示：桌面自动化测试需要保持电脑已登录状态，远程桌面断开连接可能导致测试失败。

FAQ

❓ 常见问题

首次启动需要初始化运行环境和缓存，大约需要 15-60 秒，属正常现象。后续启动会快很多。
