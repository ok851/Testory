# HuFirst UAT 桌面版 — 给最终用户

## 您拿到的是什么？

安装完成后，在开始菜单点击 **「HuFirst UAT Platform」**，会弹出一个 **像普通软件一样的窗口**，不需要自己打开 Chrome/Edge，也 **不用配置环境变量**。

（程序内部仍使用成熟 Web 技术绘制界面，但对您来说就是一个软件窗口。）

## 安装

1. 双击 **`uat_platform_setup.exe`**（这是您收到的唯一文件）
2. 按向导完成安装（安装过程可能几分钟，体积较大请耐心等待）
3. 从开始菜单 **「HuFirst UAT Platform」** 或桌面图标启动

**您不需要：**

- 安装 Python
- 安装 Inno Setup（那是给开发人员做安装包用的）
- 安装 Chrome 或 Playwright
- 修改任何环境变量或 `.env` 文件

若电脑缺少界面组件，安装程序会自动静默安装 **WebView2**（已包含在安装包内）。

## 使用注意

- 请使用 **Windows 10/11**，并保持 **已登录桌面**（远程桌面断开时，桌面自动化可能失败）。
- 首次启动可能稍慢（约 15～60 秒），属正常。
- 数据保存在安装目录下的 `data` 文件夹。

## AI 测试与 Hermes（可选能力）

平台内置 **Testory AI (Hermes)** 与浏览器画布，安装后无需手改 `.env` 即可打开 AI 测试页。若要使用「生成用例 / 优化 / 自主探索」等 AI 功能，还需满足以下之一：

1. **推荐：本机安装 [Ollama](https://ollama.com/download)**，并拉取至少一个支持工具调用的模型（建议 8B 及以上，如 `llama3:8b-instruct`）。
2. **或**：在软件内 **AI 设置** 中配置云端 API Key（OpenAI 兼容接口）。

首次打开 AI 测试页时，若未检测到可用 LLM，会出现引导条；连接中栏「打开」后的**实时画面**时，Hermes 会自动 attach 到同一浏览器窗口进行自主操作。执行成功的流程可保存为 **Skill**，供后续复用（自主学习闭环）。

## 常见问题

**窗口一直空白？**  
等 1 分钟；仍不行请联系管理员，查看安装目录 `logs` 文件夹。

**提示端口占用？**  
关闭其他正在运行的本平台，或重启电脑后再开。

**和「浏览器打开 localhost」有什么区别？**  
桌面版不会自动打开系统浏览器；界面在软件窗口内显示。
