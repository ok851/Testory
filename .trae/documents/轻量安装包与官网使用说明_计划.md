# 轻量安装包优化 + 官网使用说明 实施方案

## 一、现状分析

### 1.1 当前安装包体积构成（估算）

| 组件 | 体积 | 说明 |
|------|------|------|
| 便携 Python 运行时 | ~30-50MB | 嵌入式 Python + pip |
| Python 依赖包 | ~200-300MB | numpy、opencv、playwright、hermes-agent 等 |
| Playwright Chromium | ~150-200MB | 内置浏览器 |
| PyInstaller 多进程 | ~100-200MB | 后端 + 5个网关进程 |
| WebView2 引导程序 | ~5-10MB | 界面运行时 |
| 静态资源/模板 | ~10-20MB | 前端资源 |
| **总计** | **~500MB - 1GB+** | |

### 1.2 打包慢的原因

1. PyInstaller 编译 6 个 spec（后端 + 5个网关），每个都需要分析依赖
2. 复制大量 Python 依赖包
3. 复制 Playwright Chromium 浏览器
4. Inno Setup 压缩大体积文件耗时久

### 1.3 下载慢的原因

- 安装包体积大（500MB+），用户下载时间长
- 单 exe 分卷后用户需要下载多个文件，体验差

## 二、优化方案设计

### 核心思路：精简基础包 + 首次启动按需下载

类似于 VS Code、JetBrains 等软件的做法：
- 用户下载一个**较小的基础安装包**
- 安装后首次启动时，自动下载所需的大型组件
- 用户全程只需点"下一步"，不需要懂技术

### 2.1 从安装包中移除的内容

| 移除项 | 原体积 | 下载时机 | 用户感知 |
|--------|--------|----------|----------|
| Playwright Chromium 浏览器 | ~150-200MB | 首次运行 Web 测试时自动下载 | 运行第一个 Web 测试时等待下载 |
| OpenCV (opencv-python) | ~60-80MB | 首次使用视觉定位/AI 视觉功能时下载 | 使用视觉定位功能时提示下载 |
| numpy 可选子集 | 部分优化 | 视情况保留核心 | - |

### 2.2 保留的核心内容

- Python 运行时（保证开箱即用）
- Flask 后端 + 核心依赖
- pywebview 桌面窗口
- PyInstaller 保护的后端进程
- WebView2 引导程序
- 静态资源/模板
- Hermes AI Agent（AI 功能开箱即用）
- 接口测试、项目管理等基础功能

### 2.3 预期效果

- **安装包体积**：从 ~500MB-1GB 减少到 ~200-280MB（减少 50-60%）
- **打包时间**：减少 40-60%（跳过 Chromium 复制、减少 PyInstaller 依赖分析）
- **下载速度**：用户下载时间缩短 50-60%
- **用户体验**：单 exe 下载，安装快，AI 功能开箱即用，Web/视觉功能首次使用时后台自动下载

## 三、详细实施步骤

### 阶段一：精简安装包构建

#### 1. 修改 `prepare_offline_release.ps1`
- 移除 Playwright Chromium 浏览器复制步骤
- 可选：跳过 opencv 等大包的复制
- 添加组件清单文件 `components.json` 记录已安装/未安装的组件

#### 2. 修改 `Ensure-PortablePython.ps1`
- 在 `skipPkgs` 列表中增加可延迟安装的大包：
  - `cv2` / `opencv*`
  - （保留 numpy、hermes-agent 等核心/AI 相关依赖）

#### 3. 新增组件管理模块 `components_manager.py`
- 检测当前已安装的组件
- 提供按需下载/安装接口
- 下载进度回调
- 失败重试机制
- 组件依赖关系管理

#### 4. 修改启动检查 `launch_checks.py`
- 启动时检查核心组件完整性
- 显示可选组件状态
- 提供一键安装建议

### 阶段二：首次启动按需下载

#### 5. 新增组件下载界面
- 在设置页面增加「组件管理」选项卡
- 显示各组件状态（已安装/未安装/大小）
- 提供「安装」按钮，带进度条
- 支持后台下载

#### 6. 功能使用时自动提示
- 运行视觉定位/AI 视觉测试时，若 opencv 未安装，提示安装
- 运行 Web 测试时，若 Chromium 未安装，自动调用 `playwright install chromium`

#### 7. 管理后台支持组件下载
- 后端提供组件下载 API（可选，从官网/CDN 下载）
- 或直接使用 pip 官方源 + 国内镜像

### 阶段三：官网使用说明页面

#### 8. 新增官网文档页面 `/docs`
- 新建 `templates/docs.html` 页面
- 包含：安装指南、快速上手、常见问题、功能介绍
- 样式与官网保持一致（紫色深色主题）
- 支持锚点导航

#### 9. 官网导航增加入口
- 顶部导航栏增加「使用说明」链接
- 下载区域增加「查看使用说明」链接
- Footer 增加文档入口

#### 10. 下载区域优化
- 显示安装包大小和预计下载时间
- 增加「安装后首次启动会自动下载所需组件」提示
- 增加「查看安装指南」链接

## 五、技术细节

### 5.1 组件管理架构

```python
# components_manager.py 核心接口

class ComponentManager:
    def list_components() -> List[Component]
    def install(component_id: str, progress_callback=None) -> bool
    def is_installed(component_id: str) -> bool
    def get_size(component_id: str) -> int
```

**组件列表：**
- `chromium` - Playwright Chromium 浏览器（Web 测试必需）
- `opencv` - OpenCV 视觉库（视觉定位、AI 视觉必需）
- `mobile` - 移动端测试支持（可选）

### 5.2 下载策略

1. **核心组件**（保留在安装包中）：Python + Flask + pywebview + Hermes AI
2. **按需下载**：Chromium、OpenCV
3. **下载方式**：
   - Chromium：调用 `playwright install chromium`
   - Python 包：调用 `pip install`（支持国内镜像源）
4. **进度显示**：通过 pip 的输出解析进度，或用 tqdm
5. **失败处理**：自动重试 3 次，切换镜像源

### 5.3 国内镜像支持

在 `.env` 中可配置：
```env
PYPI_MIRROR=https://pypi.tuna.tsinghua.edu.cn/simple
PLAYWRIGHT_DOWNLOAD_MIRROR=https://npmmirror.com/mirrors/playwright
```

## 六、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 用户网络不好，下载组件失败 | 高 | 支持断点续传、多镜像源切换、手动安装指南 |
| 首次使用 Web 测试需要等待下载 | 中 | 提前在设置中下载，或后台预下载 |
| 组件依赖关系复杂 | 中 | 清晰的组件依赖图，安装时自动安装依赖 |
| 打包脚本改动影响现有构建流程 | 中 | 保留原有构建脚本，新增 -Lite 参数切换 |
| 用户不会手动安装 Python | 低 | Python 仍保留在安装包中，只移除大的可选组件 |
