约 1 分钟：用 Playwright 录制步骤（支持 XPath 优先）

无需安装本站点插件。平台步骤页的 启动 Playwright Codegen 会优先调用本仓库内的 playwright-xpath-fork（若已构建）；未构建时回退为 pip 安装的官方 Playwright（此时仍优先生成 getByRole 等）。

0. 一次性构建 XPath 优先版 Codegen（推荐）

在本机克隆/拉取的本项目根目录下执行（需已安装 Node.js 18+）：

也可在仓库根目录用 PowerShell 一键构建（内部会进入 playwright-xpath-fork 执行 npm ci 与 npm run build）：

.\tools\install_playwright_xpath_codegen.ps1 -SkipElectronBinary

或手动：

cd playwright-xpath-fork
npm ci
npm run build

npm ci 卡在 electron、或误按了 Ctrl+C：退出码 3221225786 多为「安装被中断」。请重新执行 npm ci 并不要中断，Electron 会单独下载较大文件。若只做 Codegen、不跑 Electron 测试，可在 PowerShell 中先试：$env:ELECTRON_SKIP_BINARY_DOWNLOAD='1'; npm ci，再 npm run build；若仍失败可试 npm ci --ignore-scripts 后立刻 npm run build。

必须等 npm run build 整次跑完（可能要几分钟）。只跑一半或只执行 npx playwright install 只会下载浏览器，不会生成 Inspector 界面文件，直接 node …/cli.js codegen 会报 ENOENT … lib\\vite\\recorder\\index.html。成功构建后应同时存在 lib/coreBundle.js 与 lib/vite/recorder/index.html。平台也会在检测到缺文件时自动回退为 python -m playwright codegen。可设置 PLAYWRIGHT_XPATH_CODEGEN_CLI 自定义启动命令。

1. 启动录制

在平台「测试用例步骤」页可点击 启动 Playwright Codegen（会为本机打开与下面命令等效的 Codegen + Inspector）。也可手动打开终端（Windows：命令提示符或 PowerShell），任选其一：

playwright codegen

若未全局安装，可用 Node 自带的 npx（推荐，零全局依赖）：

npx playwright codegen

指定起始网址示例：

npx playwright codegen https://你的系统地址

首次使用需安装浏览器二进制：

npx playwright install

Codegen 会打开浏览器窗口和代码窗口。你在浏览器里点击、输入、跳转，代码会实时生成。

官方 Playwright 与 XPath：为何 --target 不能改成 XPath？

在微软原版里，--target 只表示生成代码的语言（python / javascript 等），不是「全部改成 XPath」。

本仓库的 playwright-xpath-fork 在注入脚本里调整了定位器评分，使 Codegen/Inspector 默认更倾向输出 XPath（在能唯一匹配到目标元素的前提下）。若仍看到少数步骤为 getByRole，多为多匹配需离散化等场景。

2. 复制代码

在 Codegen 的代码预览里全选复制（Python 或 JavaScript 均可）。尽量包含 page.goto、click、fill 等行。

3. 粘贴到平台

打开「测试用例步骤」页 → 点击 从 Codegen 导入 → 粘贴 → 选择是否清空原有步骤 → 导入。

平台会把常见 API 转成可执行步骤；复杂 API 可能需你在步骤列表里微调。

4. 执行

用例仍在服务器无头 Playwright上运行，与录制环境无关。

5. 可选：Selenium IDE 录制（id / xpath / css 等）

若你希望录制结果里直接带 id=、css=、xpath=、linkText= 等 Selenium 风格定位，可使用 Mozilla 的 Selenium IDE 浏览器扩展；本平台支持把保存的 .side 项目 JSON 粘贴导入为步骤（与 Playwright Codegen 二选一或混用导入）。

使用方法（简要）

  1. 在 Chrome 网上应用店 或 Firefox 附加组件 搜索并安装 Selenium IDE。
  2. 打开扩展 → Record a new test in a new project → 输入项目名与起始 URL → 在浏览器中操作页面。
  3. 录制结束后在 IDE 中 File → Save project，得到 xxx.side 文件。
  4. 用系统自带记事本 / VS Code 打开该文件，Ctrl+A 全选 → 复制。
  5. 在本平台打开对应用例的 测试步骤页 → 点击 从 Selenium IDE 导入 → 粘贴 JSON → 可选「导入前清空已有步骤」→ 导入。

说明：一个 .side 里若有多条测试用例，当前只自动导入第一条；导入时会优先使用 Selenium IDE 在 targets 里给出的备选定位（例如带 @id 的 XPath），避免仅使用带随机后缀 class 的 CSS（如 .foo_a8f3c）导致再次运行找不到元素。断言、脚本、切换窗口等命令会跳过并提示。执行仍在本平台无头 Playwright 引擎上完成。
