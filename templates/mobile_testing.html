模拟器环境

模拟器（推荐）

如何安装 Android SDK / 模拟器？

推荐（无需 Android Studio）：
1. 安装 Java 11 或更高版本（可从 adoptium.net 下载）
2. 点击右上角用户菜单 → 插件市场 → 安装「Android 模拟器 SDK（命令行）」（首次约 2–4GB，请保持网络畅通）
3. 安装完成后完全退出并重新打开本软件，回到本页点击「启动模拟器」

备选： 若本机已安装 Android Studio，可在其 Device Manager 中创建虚拟手机，重新打开本软件后通常会自动识别。

更流畅的画面（推荐）： 在 插件市场 安装「scrcpy 高帧率投屏」（与模拟器 SDK 配套，一键完成）。
