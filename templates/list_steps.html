从 Playwright Codegen 导入

在本机终端执行 playwright codegen， 在 Codegen 窗口中复制生成的代码，粘贴到下方。 1 分钟教程（新窗口）

关于录制 XPath：官方 Codegen 默认优先生成 getByRole / locator(css)，不会自动整段变成 // XPath。若要在录制时用到 XPath：在 Inspector 里用 Pick locator 点元素，在定位器面板中查看是否有 // 或 xpath= 并可复制；或在开发者工具对节点「复制 → XPath」，把 page.locator('xpath=//...') 写进可复制代码。导入后平台会按规则补充 locator_candidates（尽量 XPath 优先）。纯手写 XPath 也可在「添加/编辑步骤」里将定位方式选为 xpath。 详见录制教程
